# COM3D2 陪夜技能提示词与分类重构报告

## 一、 重构概述

本项目基于 `陪夜技能整理/陪夜技能_中文分类整理.csv`（原始 541 条记录），对 `src/data/promptMenu.ts` 中的提示词三级菜单体系进行了全面重构与优化。

### 核心优化目标
1. **通用化人称适配**：
   - 保持 `{{user}}` 代表用户/玩家；
   - 鉴于 `{{char}}` 在 SillyTavern 中常被填写为卡片标题或作品名，单人情境全面升级为 **“当前女角色”**（或顺承代词 `其`、`她`）；
   - 女性多人/后宫情境统一升级为 **“当前女角色们”**；百合互动使用 **“当前女角色与同伴”**。
2. **精简扁平化二级分类**：解决原始数据中“复合管道符过多”、“层级零散碎片化”等问题，将每个大类下的二级菜单收敛为 **4 ~ 5 个标准分类**。
3. **清理游戏机制冗余条目**：剔除带有 `【】` 与 `觉醒` 标签且与常规玩法高度重合的技能；对具备独特机制的特殊玩法进行净化重命名并予以保留。
4. **沉浸式提示词生成**：所有技能均包含动作姿势、心理情境、感官细节与角色反馈。

## 四、 提示词编写规范与技术实现

1. **宏变量与人称规范**：
   - 保持 `{{user}}` 代表用户/玩家；
   - 单人情境使用 **“当前女角色”**（及其代词 `其`、`她`），避免角色卡名称非人名导致的语病；
   - 多女/后宫情境使用 **“当前女角色们”**；百合情境使用 **“当前女角色与同伴”**。
2. **文件位置**：
   - 数据定义：`src/data/promptMenu.ts`
   - UI 交互：`src/PromptBar.vue`（三级级联弹窗 + 自动插入输入框 `#send_textarea`）
3. **构建验证**：
   - 已执行 `npm run format`（Prettier 代码格式化）。
   - 已执行 `npm run build`（Vite 生产包构建，无报错，`dist/index.js` 同步更新）。
