# CUSTOM ORDER MAID 3D 2 陪夜技能中文分类整理

- 数据来源：本机 `GameData/paths.dat` 所列并实际存在的 CSV 档案，以及其中的 `yotogi_skill_*.nei`。
- 游戏启用技能 ID：830 条；按“原分类 + 日文名称”去重后：541 项。
- “玩法与姿势说明”依据游戏日文名称、分类、参与人数和动作关键词整理；原始数据本身没有独立的中文说明字段。

## 字段说明

- **类型**：将游戏内部八类日文分类翻译并改成更直观的中文。
- **玩法类型**：依据名称识别性交部位、服务方式、多人/SM/公开等标签。
- **中文名称**：保留情境修饰词与具体姿势的中文翻译。
- **玩法与姿势说明**：解释主要动作、身体朝向、使用的道具以及多人情境。
- **技能ID**：同名技能可能因性格或DLC存在多个ID，去重表中合并列出。

## 结果文件

- `陪夜技能_中文分类整理.csv`：推荐阅读，按玩法去重后的完整中文表。
- `陪夜技能_全830条ID明细.csv`：逐技能ID明细，便于与游戏数据对应。
- `陪夜技能_原始数据.csv`：直接从NEI提取的关键原始字段。
- `启用技能ID来源.csv`：每个技能ID来自哪个启用列表。
